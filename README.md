# Conquer

A roll-and-move board game of kingdoms on an 11 by 11 grassland. Roll to claim land, build on it, and when you land on someone else's land, retreat or go to war.

Play it at https://ethan-ka.github.io/conquer/

One self-contained `index.html`: rules engine, bots, pass-the-phone multiplayer, and the game art, all inline. Saves to your browser.

Designers: Jack, Aarit, Griffin, Ethan, Sam. Art: Aarit.
